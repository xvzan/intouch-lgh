# intouch-lgh 1.0.2

Read-only Python LGH/IDX archive reader. This release builds on 1.0.1 and 1.0.0.

## Changes in 1.0.2

- Add phase-level full-validation diagnostics and elapsed-time counters.
- Validate IDX-to-LGH block headers in a single pass and derive per-Tag record counts.
- Retain `IDXReader.verify_lgh()` behavior and existing public API semantics.

## Installation

```bash
python -m pip install --upgrade intouch-lgh==1.0.2
```

Core parsing is independent of NumPy and PyArrow; columnar adapters are optional.

## Compatibility and data integrity

The library preserves physical observation order, raw FILETIME ticks, and IEEE-754 bit patterns. Supported layouts are based on observed community samples, not an official AVEVA file-format specification. Unknown InTouch revisions and actively written archives are not guaranteed to be supported.
